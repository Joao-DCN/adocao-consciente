# Adoção Consciente

## Sobre o Projeto

Este é um projeto acadêmico de escopo reduzido, desenvolvido durante duas aulas práticas, com duração total estipulada de quatro horas. A finalidade principal deste repositório é projetar e construir uma interface focada na adoção responsável de animais, consolidando e revisando conceitos fundamentais de marcação e estilização web.

Este layout estático serve como alicerce estrutural para as próximas etapas da disciplina, onde implementaremos interatividade avançada e manipulação dinâmica do DOM.

## Temática da equipe

O Adoção Consciente é uma plataforma web que conecta animais que precisam de um lar a pessoas dispostas a adotar com responsabilidade. Nosso objetivo é facilitar o processo de adoção, promovendo bem-estar animal, informação e conexão direta entre adotantes e protetores.

## Objetivos do projeto

- Revisão e aplicação de **HTML Semântico** (uso correto de tags estruturais como `<main>`, `<section>`, `<article>`, `<header>`, `<footer>`).
- Desenvolvimento de Layout utilizando **CSS Flexbox e CSS Grid Layout** para garantir responsividade e organização.
- Preparação de classes e identificadores para manipulação com **JavaScript** (implementação de filtros e interatividade).
- Prática de versionamento de código e trabalho colaborativo com **Git e GitHub**.

## Tecnologias Utilizadas

- **HTML5**
- **CSS3** (incluindo Grid Layout & Flexbox)
- **JavaScript** (implementação de lógica de modo escuro e favoritos)

## Status do Projeto

Em desenvolvimento. A interface estática foi consolidada e funcionalidades iniciais de interatividade com JavaScript (Modo Escuro e Favoritar) foram implementadas. O projeto segue em preparação para integração com back-end.
